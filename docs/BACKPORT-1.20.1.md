# 1.20.1 功能回迁与 bug 修复说明

本次把 1.21.1 已完成的编辑器修复和轻量新功能移植至 Minecraft 1.20.1 / Forge 47.4.13 / Java 17。只修改 1.20.1 项目，1.21.1 项目作为只读参考。

## 新增功能

- Ctrl+Z 撤销；Ctrl+Y / Ctrl+Shift+Z 重做。保留最近 100 次文本修改，恢复文本、光标和选区。输入、删除、粘贴和 Tab 补全均进入历史，新修改会清空重做分支。
- 鼠标左键拖选多行文字，拖到编辑区上、下边缘时自动滚动扩展选区。
- 缩放窗口时重新排版，同时保留草稿、光标、选区、输出开关和撤销历史。
- 补全窗口使用不透明深色背景和前景层，跟随补全后的光标，并在屏幕底部向上显示。

历史只存在于当前编辑界面，不写入磁盘，不增加模组依赖或服务端协议。

## Bug 成因与修复方法

| 问题 | 原因 | 修复方式 |
| --- | --- | --- |
| 长文本显示内容与实际保存内容不同 | `setValue` 先截断 `value`，却用原始 `text` 排版和通知监听器 | 接受文本、排版、光标和通知统一使用截断后的内容 |
| 输入、粘贴和删除时重复刷新补全，光标出现中间跳转 | 修改先调用 `setValue` 把光标移至全文末尾，再设回插入点，期间多次调用 responder | 统一文本修改入口，先完成排版、光标与选区更新，再只通知一次 |
| 缩短长度限制后出现旧文字缓存或过界光标 | `setMaxLength` 只改字符串，没有重建行、限制光标和选区 | 截断后重建排版、限制索引，并清空无法继续使用的编辑历史 |
| Unicode 字符损坏、Ctrl+Backspace 删错范围 | UTF-16 字符索引与 Unicode code point 数量混用；截断可能切在代理对中间 | 普通删除按 code point 移动，单词删除直接使用 UTF-16 区间，截断避开代理对中间位置 |
| Tab 后光标不可见或被建议框挡住 | 全局插入点已更新，但多行视口没有跟随；弹窗仍停在旧位置 | 设置光标时自动滚动至可见行；补全完成后重新定位弹窗。保留原版的“建议区间起点 + 建议文本长度”计算 |
| 鼠标点击位置与文字错位 | Y 轴定位忽略文本区内边距，字符定位与绘制使用不同坐标 | 点击与拖选统一按文本内边距、行高、滚动量和缩进计算；按完整 code point 找字符边界 |
| 多条命令用法或错误说明叠成一行 | 循环里每次使用相同的 Y 坐标 | 每条提示递增行高，并裁剪过长内容 |
| 补全窗口透出下面文字、超出屏幕，最后选项无法滚动到可见处 | 半透明背景、与编辑器共用绘制深度、缺少边界处理和滚动偏移计算不正确 | 不透明背景，提交编辑器绘制后再绘制前景；限制宽度和行数，底部向上弹出，并按实际可见行数滚动 |
| 编辑器深层缩进、选择高亮和灰色预输入画到边框外 | 文本绘制没有限制在编辑区内 | 对编辑器文字和高亮启用裁剪 |
| 旧补全结果覆盖新输入、关闭后建议又出现 | 异步请求没有版本判断；隐藏窗口后旧请求仍能刷新界面；回调线程不固定 | 给请求编号，仅接受当前请求，在客户端线程更新界面；隐藏时使旧请求失效，异常或取消的结果不参与显示 |
| 按 Enter 或缩放窗口绕过首次服务器数据加载 | `onDone` 不检查完成按钮状态；`resize` 无条件启用控件 | 保存统一检查就绪状态和连接；编辑框与按钮保留加载状态 |
| 服务器更新覆盖未保存命令，其他方块的数据包也触发刷新 | 每次数据包都调用初始化逻辑，未确认数据包是不是当前方块 | 检查方块坐标；首次数据包初始化，后续只更新输出显示 |
| 切换跟踪输出后取消，客户端仍残留修改 | 输出按钮直接调用客户端方块对象的 `setTrackOutput` | 将开关作为界面草稿，完成时通过原版保存包提交，取消时不改方块对象 |
| 长命令访问行数据效率较低 | `LinkedList` 用于频繁按下标访问；行内定位逐字符找相同索引 | 改为 `ArrayList`，行内位置直接用全局索引减去行起点 |
| 客户端界面改动侵入服务端打开逻辑 | 重定向 `CommandBlock.use` 与 `BaseCommandBlock.usedBy`，自行处理服务端更新包 | 改为仅注入 `LocalPlayer.openCommandBlock/openMinecartCommandBlock`；保留原版服务端同步方法。移除已被替代的四个旧 Mixin/Accessor 文件 |

主要实现位于 `ModMultiLineEditBox`、`ModCommandSuggestions`、三个命令方块界面类，以及 `LocalPlayerMixin` 和 `ClientPacketListenerMixin`。

## 1.20.1 专用适配

- 字符过滤使用 `SharedConstants.filterText`，不使用 1.21.1 的 `StringUtil.filterText`。
- 光标闪烁继续使用 1.20.1 的 `EditBox.tick()` 和 `frame` 字段。
- 使用单轴滚轮接口；保留 1.20.1 的单参数光标移动重写方法，另外提供选择标记的辅助方法供拖选使用。
- 1.20.1 的 `Screen.render` 不绘制背景，因此先显式调用 `renderBackground(GuiGraphics)`，再绘制按钮、输入框和前景补全。不搬用 1.21.1 的背景模糊接口。
- Mixin 兼容级别改为 `JAVA_17`，保留 Forge 的 refmap 生成与发布 JAR 重混淆。

此前的背景重复模糊问题来自 1.21.1 的 `Screen.render` 行为，不是 1.20.1 的同一原因；本次按 1.20.1 实际接口处理绘制顺序。
