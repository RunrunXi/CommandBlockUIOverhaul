# 1.20.1 界面功能移植

以 1.21.1 当前提交 `dc73709` 的实际文件为准，保留用户调整，只修改 1.20.1。

## 已同步

- 命令与括号层级着色；可切换 IDEA Dark / 原版 ChatFormatting，Dark 配套背景与边框。
- 字符串格式化开启时，字符串内部括号参与排版和层级着色。
- 配置界面标题、三等分配置区域、勾选框、可编辑实时预览及滚动条。
- 左右括号前后断行、逗号后断行、格式化字符串、避免空行、缩进长度和行宽。
- 括号后的空格留在原行，遇到下一个非空格字符再断行；显示排版不改变命令文本。
- 点击命令框外取消焦点并隐藏建议；光标离开可见区域隐藏建议。
- 返回配置界面保留草稿、光标、选区及撤销历史，清理跨界面的拖动状态。
- P 按钮打开紧凑悬浮调色板；通过点击切换焦点，可同时编辑命令。
- RGB 输入及滑条、颜色预览、十进制/十六进制输出与复制。
- 调色板颜色在进程内缓存，初始白色，重启恢复白色，不写配置文件。
- 命令方块矿车界面重建时不再重新加载覆盖草稿。

## 保留的当前默认值

原版配色；括号前后及逗号后断行；不格式化字符串；避免空行；缩进 2；行宽 300 像素。已有配置值优先。

## 1.20.1 适配

使用 ForgeConfigSpec；保留 Forge 注册入口和 Mixin 字段；适配三参数滚轮事件、SharedConstants 文本过滤、Java 17 集合接口。勾选框使用原版构造器并将方框缩放到 17 像素。显式在控件之前绘制背景，补充输入框 tick 和焦点清理，避免直接使用 1.21.1 接口。
