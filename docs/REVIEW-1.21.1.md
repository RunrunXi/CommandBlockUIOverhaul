# 1.21.1 编辑器审查与改进

## 范围

仅修改 CommandBlockUIOverhaul-1.21.1。1.20.1 原项目和 BetterCommandBlockUI-1.20 仅供读取。参考本地 BetterCommandBlockUI 的多行定位、鼠标拖选和滚动交互，保留本项目的轻量客户端结构。本次是聚焦编辑与补全链路的审查，不代表已排除所有兼容性问题。

## 已修复的问题

| 问题 | 后果 | 修复 |
| --- | --- | --- |
| setValue 截断后仍用原始长文本排版 | 显示内容与保存内容不一致，光标与排版错位 | 统一使用最终接受的文本排版与通知 |
| 一次插入/删除多次触发 responder，且中间光标先跳到全文末尾 | 重复解析、生成错误位置的补全请求 | 一次文本更新完成光标与选区设置后，只通知一次 |
| 缩短最大长度未重建行与光标 | 旧行缓存、过界光标 | 重建排版并限制光标/选区位置 |
| 按 UTF-16 长度删除单词却转成 code point 偏移 | 含补充平面字符的命令删错范围 | 单词删除直接使用全局 UTF-16 索引；普通删除按 code point |
| Unicode 文本截断可能拆开代理对 | 字符损坏 | 截断避开代理对中间位置 |
| 鼠标定位忽略顶部内边距，缺少拖选 | 点击行与文字位置不一致，不能多行拖选 | 与绘制共享内边距和缩进计算，新增拖选及边缘滚动 |
| 多条 usage/error 提示使用同一个 Y 坐标 | 文字重叠 | 逐行排布并裁剪至屏幕边界 |
| 补全列表无屏幕边界处理，滚动到末项有偏差 | 弹窗被截断，选中项不可见 | 按可用高度限制行数，底部向上弹出，修正滚动偏移 |
| 旧异步补全请求可刷新新输入，回调线程不受限 | 提示闪回或跨线程更新界面 | 请求版本校验、客户端线程调度、异常结果保护 |
| 关闭建议后迟到的请求仍可重新弹出 | Esc/滚动后提示再次出现 | 隐藏时使旧请求失效，并清除灰色预输入 |
| Enter 保存不检查 Done 是否可用；缩放直接启用控件 | 首次服务器数据到达前可能提交未初始化草稿 | 保存统一检查就绪状态，缩放保留加载状态 |
| 后续命令方块数据包重复初始化编辑内容 | 未保存草稿被覆盖 | 首次数据包初始化草稿，后续仅刷新输出 |
| 切换输出开关直接修改客户端方块对象 | 取消操作后本地对象仍被改变 | 开关留在界面草稿中，仅确认时写入原版保存数据包 |
| 多行容器使用 LinkedList 却频繁按索引访问 | 长命令渲染产生不必要的遍历 | 改为 ArrayList，并简化行内光标定位 |

## 新功能

- 撤销/重做：100 次有界快照，恢复文本、光标和选区；新修改清空 redo 分支。
- 鼠标多行拖选和边缘滚动。
- 窗口缩放保留编辑状态和撤销历史。

没有添加持久化命令历史、文件系统存储、外部模组依赖或服务端协议。

## 验证与边界

36 项客户端自动回归检查通过；检查运行于真实 Minecraft/NeoForge 客户端，使用已应用 Mixin 的 EditBox、实际字体和 Brigadier Suggestion。该结果为迁移开发期间的验证记录；当前仓库不包含自动检查源码或运行入口。

同步界面检查使用不依赖世界的 CommandBlockEntity 夹具；没有连接真实服务器，不验证实际保存数据包的往返。异步乱序请求保护经过代码审查，尚未做真实网络延迟注入。完整视觉效果、第三方模组兼容性和大型嵌套命令的极端性能仍需游戏内验证。

后续适合单独做的小功能：文本查找、可配置缩进、可选行号。链式命令方块导航和区域选择需要更多世界交互与状态管理，暂不加入本轮轻量改进。
